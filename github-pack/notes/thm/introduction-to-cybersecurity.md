# Introduction to Cybersecurity

This introductory material covered the purpose of cybersecurity and the different responsibilities involved in protecting systems. It introduced the distinction between offensive security, which evaluates how systems may be abused under authorization, and defensive security, which monitors, investigates, and reduces risk. The most useful lesson is that both perspectives should lead to safer system design and measurable risk reduction.

Key concepts include confidentiality, integrity, availability, access control, and the importance of maintaining evidence during an investigation. The material also introduced web authorization weaknesses as a reason to verify that a user can access only the resources they are entitled to see. Evidence handling requires preserving context and recording actions so that findings can be reviewed.

Defensive controls include server-side authorization checks, least privilege, secure session management, audit logging, and a documented incident-handling process. I would do differently by connecting each security concept to a practical defensive control and by keeping study notes focused on lessons rather than platform answers.
