## Platform rules and publication safety
All HTB material remains learning notes unless the owner marks the exact item retired in status-needed.csv. No HTB walkthrough has been prepared because retirement status is unknown. TryHackMe material is treated as active: these notes contain no flags, answers, passwords, hashes, tokens, keys, room-specific exploit code, or step-by-step room solutions. No exam or certification content is included.
All notes carry the requested non-affiliation statement. Review each file and confirm platform rules before publishing. The pack contains no screenshots or copied platform walkthroughs.

## Review status
Learning notes are private-review and should not be published until approved. Cheatsheets contain generic defensive guidance and placeholder-based commands. Some cheatsheet material is standard reference knowledge rather than a direct summary of the supplied documents; see the accompanying review-notes.md in WORK.

## Scope limitations
No verified CV, ALX certificate, or standalone professional photograph was present in the supplied archives. No document upload is proposed. Items flagged for credentials or private infrastructure indicators were excluded in full. See status-needed.csv and review-notes.md in WORK.
